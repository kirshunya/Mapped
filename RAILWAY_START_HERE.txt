🎯 QUICKEST START (3 Steps, 20 Minutes):
═══════════════════════════════════════════════════════════════════════════════

1️⃣  Install Railway CLI
    npm install -g @railway/cli

2️⃣  Prepare Environment
    cp .env.railway .env
    # ⚠️  IMPORTANT: Edit .env and change ALL passwords!
    #     DB_PASSWORD, JWT_SECRET, MINIO_PASSWORD

3️⃣  Deploy
    railway login
    railway init
    railway up

    ✅ Done! Your app will be live in 15-20 minutes
